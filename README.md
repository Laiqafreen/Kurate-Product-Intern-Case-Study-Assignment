Kurate — Product Intern Case Study

This repository contains my Product Intern Case Study Assignment for Kurate, focused on the design and evaluation of the Trusted Search feature.

The case study covers four key areas:

Product Discovery — identifying the user problem and defining Trusted Search.

Buildable System — proposing the search approach, architecture, and key trade-offs.

Release Quality — defining bugs, test cases, release gates, and stop-ship conditions.

Product Learning — analyzing product data and designing an experiment to improve search relevance.


The assignment demonstrates my approach to product thinking, analytical reasoning, prioritization, quality, and data-driven decision-making.
